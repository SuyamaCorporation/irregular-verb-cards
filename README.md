# 13 - 不規則動詞暗記カード

**ビルド日**: 2026-11-03
**カテゴリ**: fun
**slug**: irregular-verb-cards

## 概要
英語の不規則動詞変化（原形・過去形・過去分詞）をフラッシュカード形式で暗記できるSPA。40語以上収録し、正解率グラフとストリーク表示付き。

## 機能
- 40語以上の不規則動詞データ内蔵（be/go/have等）
- CSSアニメーションによるカードフリップ（クリックで裏返し）
- モード切替: 原形→過去/過去分詞 / 日本語→英語
- 難易度フィルター: 初級・中級・上級・全て
- 正解/不正解ボタンで回答記録
- 各動詞の正解率バー表示
- 総合正解率バー
- localStorage進捗保存（正解・不正解数をカード単位で保持）
- 統計リセットボタン
